# 🚗 Solar-Powered Automatic Number Plate Recognition System

An AI-powered Automatic Number Plate Recognition (ANPR) system built using **Raspberry Pi 4 Model B**, **IR Camera**, **YOLOv8**, **OpenCV**, and **Tesseract OCR**. The system automatically detects vehicles, localizes number plates, extracts the registration number, and stores the results locally. It is designed as a solar-powered, energy-efficient solution for traffic monitoring, parking management, and smart transportation.

---

## 📌 Features

- 🚗 Vehicle Detection using YOLOv8
- 🔍 Number Plate Detection
- 🔤 OCR-based Number Plate Recognition
- 💾 Local Data Storage
- ⚡ Solar-Powered Embedded System
- 🍓 Raspberry Pi 4 Based Deployment
- 📷 IR Camera Support
- 🌙 Day & Night Operation
- 📊 Confidence Score Display
- ⏱️ Processing Time Measurement
